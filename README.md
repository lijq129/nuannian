## 打开与继续调整

双击 `index.html` 可直接离线使用。内容、照片和图标均在本目录；烹饪视频仍需网络。

- `css/design.css`：当前有效的颜色、排版、图标尺寸和响应式样式；覆盖原基础样式。
- `js/app.js`：页面结构、统一图标和交互。
- `DESIGN_NOTES.md`：设计原则、素材来源、验证范围。
- `js/recipe-bv.js`：当前正式烹饪视频目录（`VIDEO_MAP`），含来源标题、作者、时长和差异说明。
- `VIDEO_NOTES.md`：视频来源、核验边界、更新步骤与本轮测试记录。
- `qa/overview.png`：主要页面的预览拼图。
- `qa/results.json`：布局和运行检查结果。

之前的内容修复继续有效。数据仍保存在当前浏览器中；切换浏览器或从另一网址打开不会自动迁移，请先在「我的 → 我的 → 数据备份与更新」导出 JSON，再在新环境导入。字段和更新方法见 `DATA_UPDATE_GUIDE.md`。

返回导航：使用页面顶部的“返回”按钮；导航路径仅保留在本次打开期间，刷新后重新开始，不接管浏览器自身的前进/后退。外部来源链接仍在新标签页打开，原应用页面保留。后续新增应用内跳转统一调用 `go(view, changes)`，不可在调用前修改目标标签或筛选，以免丢失来源状态。课程与视频之间仍不新增无实际对应关系的关联。

本轮检查：`scripts/navigation-check.cjs` 覆盖首页入口、中文搜索结果、明日推荐的直接菜谱/关键词跳转、收藏、多级返回、状态与滚动恢复、视频停止、跟练退出，以及 320/390/768/1280 宽度的大字号布局；结果见 `qa/navigation-results.json`。跟练视频的离线交互检查和中文输入法检查亦通过；本轮未重新联网逐段验证视频内容。

看做法：「饮食 → 家常菜谱」里展开一道菜即可看完整做法与视频；「今日三餐」点菜名也能就地展开做法。「明日推荐」页只展示采购清单和明日要做的菜式，不展开做法，点某道菜会跳到「家常菜谱」查看。文字步骤下方即是播放器，点击播放即可。视频需要联网，默认不自动播放；收起或切换页面会停止，原站链接可用于加载失败时继续观看。

看跟练：进入「活动养护 → 跟练视频」，先完成当天状态确认，再展开条目并主动加载播放器，无需第三方搜索。原有 3 组 14 条和下方 2 条补充均保留；高强度、瑜伽和颈肩/体态类内容需先在个人档案记录专业人员确认。展开卡片不会连接第三方平台，只有点击“加载跟练视频”才会连接。收起、切换视频或离开页面会销毁播放器，默认不自动播放、不自动打卡。平台仍可能显示自己的品牌、登录提示或清晰度限制。视频可播放不等于医疗审核。正式目录为 `js/data-fit-video.js`，详见 `FIT_VIDEO_NOTES.md`。

本版本自动化检查通过：保留 200 道菜谱、13 套图文课程和 16 段跟练视频；覆盖旧数据迁移、档案编辑、JSON 导入导出、饮食条件、每日运动筛查、专业确认门槛、中文输入法、导航返回，以及 320/390/768/1280 宽度布局。结果见 `qa/product-results.json`、`qa/navigation-results.json`。本轮播放器测试使用离线替身，未重新联网逐段验证第三方视频可用性。
